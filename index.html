Questions

Where does my code go?
Nowhere. Agents run on the machines you connect, in your repositories, with your own logins. Tackora stores tickets, conversations, run logs for 30 days and pull request links — never the repository.
Which agents can I use?
Claude Code, Codex, OpenCode, the DeepSeek Harness, Gemini CLI, GitHub Copilot, Qwen Code, Amp, Cursor, Droid and Pi — each signed in the way you already use it, picked per ticket.
Do I pay for runners or agent usage?
No. Runners are unlimited on every plan; they run on your machines. Agent usage is billed by each agent's own provider, on your existing plan or key.
GitHub only?
GitHub and GitLab, including self-hosted GitLab: pull and merge requests, issue labels and comments as triggers.
What does a runner need?
Node.js 22 or newer, git, and the agents you want to use, installed and signed in. Linux, macOS and Windows.
Can we host Tackora ourselves?
A runner can point at any Tackora server. Write to us about running the server inside your company.
