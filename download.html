How it works

On this page

Download ​

Tackora 0.3.6 for Linux and Windows (64-bit). You also need a coding agent installed — Claude Code for Claude tickets, or the DeepSeek Harness for dsh tickets.

Linux ​

One command. It picks the right package for your distro (AUR on Arch, .deb on Debian/Ubuntu, .rpm on Fedora/openSUSE) and falls back to the AppImage:

bash
curl -fsSL https://anas1412.github.io/tackora/install.sh | bash

Or download the AppImage, which runs on any distro: chmod +x Tackora_*.AppImage and run it.

Windows ​

Download Tackora_0.3.6_x64-setup.exe and run it. It installs for your user, no admin rights needed.

Windows shows "Windows protected your PC"

Builds aren't code-signed yet. Choose More info → Run anyway.

Other packages: .deb, .rpm, .msi (for managed Windows installs) and tackora-bin on the AUR. Older versions are on the releases page.
